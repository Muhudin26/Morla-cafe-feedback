# MORLA CAFÉ — Customer Feedback Website

## What's included
- `index.html` — responsive Somali feedback form
- `morla-logo.png` — supplied logo image

## Form behavior
Customers can enter their name (optional), select Cabasho/Talo/Mahadcelin, select a category, and write details.
The WhatsApp button opens a pre-filled message to **+252 610 362525**.
The Email button opens a pre-filled email to **lastkellar@gmail.com**.

Note: the customer's device must have WhatsApp/email support configured. The customer must press Send themselves. This static site does not store submissions in a database.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `morla-cafe-feedback`.
2. Upload `index.html` and `morla-logo.png` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish. The site URL will look like `https://YOUR-USERNAME.github.io/morla-cafe-feedback/`.

## Create the working QR code
After GitHub Pages gives you the real public URL, generate a QR code that points to that exact URL. A QR cannot reliably point to the website until the published URL exists.
